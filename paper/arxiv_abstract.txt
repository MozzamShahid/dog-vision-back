Fine-grained dog breed identification is challenging, and more so when extended to real-time video containing multiple subjects. Existing solutions achieve high accuracy on curated single-dog images but rarely address simultaneous localisation and classification of several dogs in live camera streams. We present a two-stage inference pipeline combining lightweight object detection with calibrated ensemble classification. Stage 1 uses EfficientDet-Lite0, a 5.3M-parameter COCO-pretrained detector, to localise every dog in a frame. Stage 2 classifies each detected region into one of 120 breeds using an ensemble of EfficientNetV2S (21.0M parameters) and ConvNeXtTiny (28.3M), both ImageNet-1K pretrained and fine-tuned on the Stanford Dogs Dataset (20,580 images). We compare three backbones (MobileNetV2, EfficientNetV2S, ConvNeXtTiny) trained under an identical three-phase protocol with MixUp and CutMix augmentation. Post-hoc temperature scaling is applied independently to each classifier before element-wise softmax averaging. The ensemble reaches 94.04% top-1 and 99.43% top-3 accuracy on the Stanford Dogs Dataset, a 50.1% reduction in top-1 error over a MobileNetV2 baseline (88.05%). Temperature scaling cuts expected calibration error from 0.1273 to 0.0240 while leaving accuracy essentially unchanged, yielding confidence scores that track empirical accuracy. For real-time use, a single-model variant runs at 4.2 frames per second on 8 vCPU cloud hardware, processing all detected regions in one batched forward pass. The system is deployed as a Progressive Web Application accessible from any camera-equipped mobile browser using WebSocket frame streaming with send-after-response backpressure. We report a latency-accuracy trade-off analysis, reliability diagrams, and multi-subject throughput benchmarks. All code, trained weights, and reproducibility instructions are publicly available.
